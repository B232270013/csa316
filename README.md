# Social & Event System — F.CSA316

Программ хангамжийн хөгжүүлэлтийн процесс. AI тусламжтай боловсруулсан лабораторийн материал.

## MVP
Event create/list, validation, PostgreSQL эсвэл in-memory demo, responsive web. Бүртгэл, найз, урилга, RSVP, group, notification бүрэн хэрэгжээгүй. Production-ready биш.

## Run
`npm install && npm test && npm start` → http://localhost:3000. PostgreSQL: `docker compose up --build`.
