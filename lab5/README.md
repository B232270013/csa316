# Архитектур
Layered client-server: UI, API, бизнес логик, өгөгдөл. Жижиг багт нэг сервер удирдахад хялбар. Давхарга тус бүрийг тестлэх боломжтой. PostgreSQL нь холбоост ивент өгөгдөлд тохирно. PlantUML файлууд шинэчилсэн санал бөгөөд өмнө хамгаалсан диаграммыг орлохгүй. PDF экспорт хийх: plantuml -tpdf lab5/*.puml
