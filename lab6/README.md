# Branching and Review
Хоёр гишүүн ижил greeting.txt мөрийг өөрчилнө. feature/greeting-a, feature/greeting-b branch үүсгэж PR нээнэ. Эхний PR merge хийсний дараа хоёр дахь branch дээр git merge main ажиллуулж conflict засна. Хоёр гишүүн тус бүр 2 бодит review comment бичнэ. Нотолгоо: PR URL, conflict screenshot, merge commit. Хамтрагчийн review хараахан хийгдээгүй.
